# Changelog

## Complete shareware episode

- DOOM now includes E1M1 through E1M8 and the secret map E1M9. The board stages each level from an eMMC map pack, and completing Hangar advances to Nuclear Plant.
- Fixed the missing E1M1 door texture by preserving DOOM’s reserved texture index in the WAD reducer.
- Added pitched beeper cues for guns, explosions, pickups, doors, and player damage.
- Verified all nine maps render on scanner 1. The bench run used the debugger to advance later levels, exercised the secret return to E1M4, and reached the episode finale.
- Split the public guides into setup, play, development, and recovery. Earlier firmware experiments moved into [archive](archive).

## HackerZone Arcade

- Added a built-in selector, individual loading screens, and games including Snake, Pong, Breakout, Neon Circuit, and the native Dino Run.
- Added optional original Midway Pac-Man from local ROMs and six optional CHIP-8 games from eMMC.
- Added USB viewing and keyboard controls, including lossless native 320 × 240 capture where supported.
- Added support for the scanner’s status LEDs and beeper across the arcade.

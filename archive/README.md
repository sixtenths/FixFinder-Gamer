# Hardware experiments archive

The USB-Build directories preserve the early USB experiments through V7. The [RGB test](rgb-test) preserves the original display experiment, including a historical HTML copy that was once named as a PDF.

Use the [current installation guide](../docs/SETUP.md) for a working build and the [recovery guide](../docs/RECOVERY.md) for the verified V8 baseline. The active build still uses the original [C runtime stubs](USB-Build/crt_stubs.c) from this archive.
